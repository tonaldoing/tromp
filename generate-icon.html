📋 Instrucciones

  1. Haz click en "Descargar" para cada ícono (192px y 512px)
  2. Guarda los archivos en la carpeta c:\www\trompocostos\public\
  3. Reemplaza los archivos existentes icon-192.png y icon-512.png
  4. Rebuild la app con npm run build
  5. ¡Listo! Tu PWA tendrá el nuevo ícono 💸
